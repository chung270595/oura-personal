# Privacy Policy

This website describes a personal tool for viewing Oura Ring data.
The website itself does not ask for Oura credentials or display ring data.

The planned tool will request permission through Oura to read daily
sleep, activity, and readiness summaries from the owner's Oura account.
The owner can revoke access through their Oura account.

This policy will be updated before the tool is used to explain how
retrieved data is stored, shared, and deleted.
